01 / From more data to SGD

Why does more data lead us to stochastic gradients?

1. Turn learning into an optimization problem

In the previous lesson, one training point gave only the condition w1 + w2 = 1. Adding varied inputs determined the weights separately. More informative data constrain the weights—but processing all those examples at every update costs more. More complex neural networks make each example’s forward and backward passes more expensive, increasing the cost further.

As before, y is the prediction and w represents the network weights. Write the target as z (instead of t in the previous lesson), reserving t for time in the ODE. Biases are updated in the same way. For one example, the loss is:

L = (y − z)²

For N examples, use the same average squared error as before. The prediction yi(w) depends on the current weights; the target zi is fixed:

L(w) = 1N ∑i=1N [yi(w) − zi]²

The gradient tells us how the loss changes with each weight; its negative points downhill.

∇L(wk) = 1N ∑i=1N ∇[yi(wk) − zi]²
wk+1 = wk − α∇L(wk)

This is the previous rule wnew = wold − α∇L, now indexed by update k. The learning rate is still α. A full-gradient update processes all N examples before changing the weights.

More data increases full-gradient cost, even with the same network.

2. Take a cheaper step using a sample

This method is called stochastic gradient descent (SGD). “Stochastic” refers to the random choice of training examples. Here we use the mini-batch version.

A mini-batch is a small, randomly selected group of training examples. At update k, call the selected batch Bk. The same index connects the current weights wk, the selected batch Bk, and its gradient estimate ∇LBk(wk). The size |Bk| counts its examples. Let LBk(w) be the average squared-error loss on this batch. Its gradient estimates the full-loss gradient:

∇LBk(wk) = 1|Bk| ∑i∈Bk ∇[yi(wk) − zi]²
wk+1 = wk − α∇LBk(wk)

Example: with 20,000 training examples and a mini-batch of 64, a full-gradient update processes 20,000 examples; an SGD update processes 64. Each update uses less computation. However, because its direction is only an estimate, SGD may need more updates to reach a similar loss. Total training time depends on both the cost of each update and how many updates are needed.

3. Understand the price of sampling

Different batches can suggest different changes to the weights. A mini-batch gradient is an estimate of the full gradient.

Hold the weights wk fixed and try several random batches. Their gradient estimates may differ because they contain different examples. Uniform sampling means each training example has the same chance of being selected. With this sampling rule, averaging over all possible batches gives the full gradient.

How to read the expectation formula
E[∇LBk(wk) | wk] = ∇L(wk)

E means the average over the random batch choices. The vertical bar means “with the current weights wk held fixed.” The right side is the gradient computed using the entire dataset. Individual estimates can differ from it; they agree on average.

The sampling error is the difference between the gradient from the selected batch and the full-dataset gradient. Call this difference ξk:

ξk = ∇LBk(wk) − ∇L(wk)
∇LBk(wk) = ∇L(wk) + ξk

This difference is the noise in the gradient estimate—not an error in the calculation. A larger batch averages over more examples, so the estimate usually varies less from batch to batch. But processing more examples makes each update more expensive.

The ball retains velocity from its earlier motion. Friction and rolling resistance gradually dissipate energy. In optimization, we can give weight updates a similar memory; this leads to momentum.

This is a physical analogy: a rolling ball has rotational motion, and the printed model’s shape and friction affect its path. The simulation below compares optimization rules on a simplified valley.

From a moving ball to moving weights

The ball’s next motion depends on both the current slope and the velocity it already has. We can give weight updates a similar memory. A displacement is the change in the weights during one update. Momentum keeps part of the previous displacement and combines it with the new downhill step.

If several gradients suggest moving in the same direction, the new steps reinforce the retained motion. If a component keeps reversing direction—up, then down, then up—its contributions partly cancel instead of building steadily.

In a narrow valley, this can preserve progress along the valley while reducing repeated changes across it. A noisy batch also has less immediate control over the next direction. However, retained motion can carry the weights past a minimum, so more memory is not always better.

Why is this a problem? A step can move away from good weights because of the sampled batch, then another step moves back. Momentum offers another approach: keep some earlier motion so one noisy batch has less immediate control.

The weights zigzag across the valley while moving more slowly along it. This happens because the step size is large relative to the steep direction—not because of random batches.

Why is zigzagging a problem? Many updates move back and forth across the valley while making little progress along it toward the minimum. Each update still costs computation. A smaller learning rate reduces overshooting across the valley, but also makes progress along its floor slower. Momentum aims to retain useful forward motion while partly canceling the alternating sideways contributions.

What should memory preserve? In the narrow valley, steps tend to agree along the floor but oppose each other across it. Momentum retains some past motion: agreeing contributions build up, while opposing contributions partly cancel. In the noisy example, memory reduces how abruptly one batch can change the direction. It does not remove all noise or guarantee a better step.

1. What information does momentum add to gradient descent or SGD?

It retains part of the previous displacement, wk − wk−1, as well as using the current gradient. This gives updates a memory of earlier motion.

Steps along the valley tend to agree, while steps across it often reverse. Retaining earlier displacement lets agreeing contributions build up and opposing contributions partly cancel.

03 / From the ODE to momentum

Where does the memory term come from?

What makes the ball keep moving after it reaches the valley bottom? Start with the ball itself: gravity changes its motion, inertia carries it onward, and resistance slows it down. An ODE lets us describe these effects together.

We will first derive a discrete rule for the ball’s position. Only after that will we compare its structure with the momentum update from Section 2.

1. Write an equation for the motion

Let x(t) be the ball’s position along the valley. Its velocity is dxdt and its acceleration is d2xdt2. Let f(x) denote gravitational potential energy: lower positions in the valley have lower f. As on the board, write the downhill force as −∇f(x). For a one-dimensional position, ∇f(x) = dfdx(x).

Use an idealized model with constant effective mass m and resistance proportional to velocity. It captures inertia and damping; it is not a complete model of a ball rolling on an arbitrary surface.

Newton’s law is mass × acceleration = total force. Use a downhill force and a friction force:

md2xdt2 = −∇f(x(t)) − cdxdt
md2xdt2 + cdxdt = −∇f(x(t))
  • Downhill force: −∇f(x) changes velocity toward lower potential energy.
  • Mass: m > 0 provides inertia, so motion does not instantly follow a new slope.
  • Friction: −cdxdt, with c > 0, opposes velocity and gradually reduces retained motion.

This equation is second order because it contains acceleration. We need both a starting position and a starting velocity. A particle can keep moving through a point with zero slope because it already has velocity—just as the ball can pass through the valley bottom.

2. Approximate the ODE numerically

The ODE in Part 1 describes a continuous trajectory. To approximate its solution on a computer, choose a time step h > 0 and compute positions at tk = kh. The value xk approximates the ball’s position x(tk).

One numerical scheme for this ODE computes the next position from the current and previous positions:

xk+1 = xk − h2m + ch∇f(xk)
+ mm + ch(xk − xk−1)

Starting from the initial position and motion, repeating this update produces a sequence of positions that approximates the ODE’s solution. The gradient supplies the downhill contribution, while xk − xk−1 carries information about earlier motion.

Where does this formula come from? We will derive it next by replacing the ODE’s derivatives with finite differences and solving for the next position. Try each challenge before revealing the solution.

4. Compare the ball’s update with momentum

The discrete ball model gives:

xk+1 = xk − α∇f(xk)
+ β(xk − xk−1)

Here the coefficients come from the physical parameters:

α = h2m + ch, β = mm + ch

Now make the connection: replace the ball’s position x by the network weights w, and potential energy f by training loss L. The scalar energy derivative becomes the loss gradient:

wk+1 = wk − α∇L(wk)
+ β(wk − wk−1)

Both rules combine a downhill step with retained displacement. In training, α and β are chosen directly. Using the mini-batch loss gradient gives the SGD version from Section 2:

wk+1 = wk − α∇LBk(wk)
+ β(wk − wk−1)

Starting the ball at rest means x−1 = x0. Starting the optimizer at rest similarly means w−1 = w0.

5. Put the rule into practice

We began with noisy gradient estimates, explored the ball’s motion, and derived the memory term from a second-order ODE. Now use that same rule to predict a weight update.

wk+1 = wk − α∇LBk(wk)
+ β(wk − wk−1)

Read the update as three contributions: current weights, a new downhill step, and retained displacement. Start at rest with w−1 = w0.

Section 3 checkpoint

Try each question before revealing the explanation.

1. Which term in the ODE introduces memory?

The acceleration term compares successive interval velocities. When we rearrange the discrete equation, it produces the previous displacement xk − xk−1.

2. Why does the denominator contain m + ch?

After multiplying by h², both inertia and damping multiply the new displacement. Their coefficients add to m + ch.

3. How does greater friction affect retained motion?

With m and h fixed, increasing c enlarges the denominator of β = mm + ch. Therefore β decreases, and less previous displacement is retained.

4. How does the ball’s formula become a weight update?

Replace position x with weights w, and potential energy f with loss L. The downhill energy derivative becomes the loss gradient, while the previous-displacement term keeps the same form. For SGD, use the mini-batch loss gradient.

5. How do we represent starting at rest?

Set x−1 = x0 for the ball, or w−1 = w0 for the optimizer. The initial previous displacement is zero.

04 / How much memory?

Why can more memory make things worse?

Momentum helped in Section 2, but the lesson also warned that more memory is not always better. The ball explains why. With very little friction, it rolls back and forth across the valley for a long time. With a lot of friction, it creeps toward the bottom. You have met these two behaviors before: underdamped and overdamped motion. This section finds the same cases inside the momentum rule and uses them to choose β.

To show the pattern clearly, this section uses exact gradients, with no sampling noise. Section 2 added a little noise, so its update counts can differ from the ones here by a few updates.

1. Study one direction at a time

For the valley L(w₁, w₂) = ½(w₁² + 12w₂²), the gradient is (w₁, 12w₂). Each component depends only on its own weight, so the momentum rule splits into two separate one-dimensional rules. In each direction the loss has the form ½aw² with gradient aw, where a measures steepness: a = 1 for the flat direction w₁, and a = 12 for the steep direction w₂.

How does the loss connect to the ball? Recall from Section 3 that the loss L plays the role of the ball’s potential energy f, and the downhill force is the negative derivative of that energy. In one direction the loss is ½aw², so the force on the ball is −aw. It pulls toward the minimum, and pulls harder when the weight is farther away. This is Hooke’s law for a spring with stiffness a: the flat direction acts like a weak spring (a = 1), and the steep direction like a spring twelve times stiffer (a = 12). At the starting point (4, 2), for example, the pull is −1 · 4 = −4 in the flat direction but −12 · 2 = −24 in the steep direction.

Writing the ball’s position as x, this downhill force −ax turns the equation of motion into the damped spring equation:

md2xdt2 + cdxdt + ax = 0

Its characteristic equation is mr² + cr + a = 0, and the discriminant decides the motion:

ConditionRootsMotion
c² > 4matwo real rootsoverdamped: creeps to rest without oscillating
c² = 4maone double rootcritically damped: fastest return without oscillating
c² < 4macomplex pairunderdamped: oscillates while it settles

2. A characteristic equation for the update

In one direction, the momentum rule wk+1 = wk − αawk + β(wk − wk−1) collects into

wk+1 = (1 + β − αa)wk − βwk−1

For the ODE you guessed x = ert. For an update rule, the matching guess is wk = rk.

Challenge 1

Find the characteristic equation of the update

Substitute wk = rk into the rule above and divide by rk−1.

Need a hint?

Write wk+1 = rk+1 and wk−1 = rk−1. Every term then shares the factor rk−1.

Reveal solution

Substituting gives rk+1 = (1 + β − αa)rk − βrk−1. Dividing by rk−1:

r2 − (1 + β − αa)r + β = 0

The general solution combines r₁k and r₂k. If both roots satisfy |r| < 1, the weight shrinks to 0, and each update multiplies the remaining error by roughly

ρ = max(|r₁|, |r₂|)

A smaller ρ means faster convergence. The discriminant D = (1 + β − αa)² − 4β sorts the update into the same three cases as the ball:

ConditionRootsWhat the weight does
D > 0two real rootsoverdamped: creeps; the larger root sits close to 1
D = 0one double rootcritically damped
D < 0complex pairunderdamped: overshoots and oscillates, with |r| = √β

A negative real root makes the weight change sign at every update. That is the zigzag in Section 2’s exact-gradient plot. With no memory, the steep direction’s only nonzero root is 1 − αa, which equals 1 − 0.14 · 12 = −0.68 at α = 0.14.

Challenge 2

Why is |r| = √β when the roots are complex?

Explain using the coefficients of the characteristic equation.

Need a hint?

Complex roots of a real quadratic come in a conjugate pair, s + ti and s − ti, and both have modulus √(s² + t²). For r² − Br + C = 0, the product of the roots equals C.

Reveal solution

The product of the roots is (s + ti)(s − ti) = s² + t² = |r|², and it must equal the constant term β. So |r|² = β and |r| = √β. In the underdamped case, the learning rate changes how fast the weight oscillates, but not how fast the oscillation dies out.

With β = 0.6, the steep direction is underdamped with |r| = √0.6 < 1, so momentum still converges. In general, the update is stable when 0 ≤ β < 1 and αa < 2(1 + β). 4. Choose β by critical damping

The flat direction is the slow one, so it controls the total number of updates. Its rate is smallest where its two roots meet. That is critical damping:

(1 + β − αa)2 = 4β

Challenge 3

Solve for the critical value of β

Find β in terms of αa, then evaluate it for the flat direction with α = 0.06.

Need a hint?

Take square roots: 1 + β − αa = 2√β. Treat √β as the unknown in a quadratic.

Reveal solution

Write s = √β. Then s² − 2s + (1 − αa) = 0, so s = 1 ± √(αa). We need β < 1, so take the minus sign:

β* = (1 − √(αa))2

For a = 1 and α = 0.06, β* = (1 − 0.245)² ≈ 0.57. The lesson’s default β = 0.6 is almost exactly critical damping for the flat direction. At this β, the steep direction is underdamped with the same rate √β, so the two directions are balanced.

Why did β = 0.6 beat β = 0.57? The rate ρ is smallest at critical damping, but at a double root the solution has the form wk = (A + Bk)rk. The extra factor k slows early progress, just like the tert term in a critically damped spring. Settings just on the underdamped side often reach a target slightly sooner. Treat the critical value as a guide: β near β* works well, while β far from it in either direction is slow.

Connect this back to the ball with β = mm + ch. A small β means heavy friction relative to mass, so the motion is overdamped. A β close to 1 means a slippery valley, so the motion is underdamped. Choosing β is choosing how much friction the optimizer feels.

3. Why does the learning rate not change the rate in the underdamped case?

For complex roots, |r|² equals the product of the roots, which is β. Changing α moves the roots around a circle of radius √β. It changes how fast the weight oscillates, not how fast the oscillation shrinks.

4. Compare c² = 4ma for the ball with (1 + β − αa)² = 4β for the update. What do they have in common?

Both say the discriminant of the characteristic equation is zero, so the roots coincide. That is critical damping in each setting: the boundary between creeping and oscillating.

5. Why choose β using the flat direction rather than the steep one?

The flat direction converges most slowly, so it limits the total number of updates. Critically damping it speeds up the slow direction, and the steep direction then runs at the same rate √β.
